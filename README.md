# 🎵 Music Player

A modern and responsive **Music Player** built using **HTML, CSS, and JavaScript**.

This project is designed to practice JavaScript fundamentals, DOM manipulation, event handling, and the HTML5 Audio API.

## 🚀 Live Features

* ▶️ Play music
* ⏸️ Pause music
* ⏭️ Next song
* ⏮️ Previous song
* 🎵 Display song title
* 👤 Display artist name
* 🖼️ Song/album cover
* 📊 Interactive progress bar
* ⏱️ Current song time
* ⌛ Total song duration
* 🔊 Volume control
* 🔇 Volume adjustment
* 📋 Playlist
* 🔄 Automatic next song / autoplay
* ⌨️ Keyboard controls
* 📱 Responsive design for mobile devices

## 🛠️ Technologies Used

* **HTML5** — Structure of the music player
* **CSS3** — Styling, layout, animations and responsive design
* **JavaScript** — Music controls, playlist, DOM manipulation and events
* **HTML5 Audio API** — Playing and controlling audio

## 🎮 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Add your music files inside the `songs` folder.
4. Add song cover images inside the `images` folder.
5. Update the song information in `script.js`.
6. Open `index.html` in your browser.
7. Click the **Play** button to start listening.
